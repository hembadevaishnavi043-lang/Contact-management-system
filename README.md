# Contact-management-system

Introduction

A Contact Management System is an application used to store and manage contact names and phone numbers. Hash tables help store and retrieve contact information quickly using a hash function.

Problem Statement

To develop a contact management system using a hash table that stores contact names and phone numbers and retrieves them efficiently. Collision resolution is used when multiple contacts generate the same hash index.

Objectives

- To store contact names and phone numbers.
- To search contacts quickly using hashing.
- To handle collisions using chaining.
- To display all saved contacts.

Technology Used
- Programming Language: Python
- Data Structure: Hash Table
- Collision Resolution: Separate Chaining

 Advantages

- Fast contact searching.
- Efficient storage and retrieval.
- Handles collisions using separate chaining.
- Existing contacts can be updated.
